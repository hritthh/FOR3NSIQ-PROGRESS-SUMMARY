Planned vs Actual S-Curve

▼

┅ Planned baseline (each task’s weight spread over its Planned Start→End)   ━ Actual (sampled weekly up to the data-date marker). Planned % is computed from the baseline dates; Actual % ramps each task from its Actual Start to its Actual End (or the workbook’s Today’s Date) up to the reported Activity Progress %. Use the View control to switch between Overall (full baseline + Actual overlay) and Yearly / Both. In Yearly view both lines start at 0% on 1 Jan and are shown as a % of that year's planned scope — measuring work done within the year. The Actual can run above Planned when a project clears a backlog (in-year catch-up).

🗂️Project Performance Dashboard

Project ↕ Planned % ↕ Actual % ↕ Variance ↕ SPI ↕ Activities ↕ Planned Weight ↕ Health ↕
SPI = Actual ÷ Planned progress to date. Health: ✅ On/ahead (SPI ≥ 0.98) · ⚠️ Slight slip (0.90–0.98) · ⛔ Behind (< 0.90). Sorted by largest schedule variance by default.
